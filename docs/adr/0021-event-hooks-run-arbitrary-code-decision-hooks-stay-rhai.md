# Event hooks run arbitrary code at station events; decision hooks stay in-process Rhai

A decision hook (pool, sequencer, scorer, bumper) is Rhai run in-process during generation, and its return value decides what airs. An event hook is an entry in a `hooks:` list in `station.yaml` or `channel.yaml`. It names a trigger (`cron` with an interval, `schedule_item_change`, `playback_item_change`, `viewer_start`, `viewer_stop`, or a daemon lifecycle event), a body (a Rhai script run on a worker thread, or any executable that receives the event as JSON on stdin) and its grants, and it cannot change the schedule. A script can run programs, make HTTP calls or download files only when granted. A script that starts outside work owns its own deduplication, and the station keeps no record of executions.
