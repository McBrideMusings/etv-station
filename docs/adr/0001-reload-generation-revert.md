# Reload-generation prepare failures revert to the last-known-good config

The station daemon reloads config on SIGHUP by tearing down the current generation and preparing a new one through a single prepare path (`prepare_generation`) shared by the startup and reload cases. A prepare failure on the first generation is fatal. A prepare failure on a reload generation reverts the whole generation to the last config that prepared cleanly and re-spawns that instead of tearing down channels that were streaming fine. If the reverted config also fails to prepare, `Arc::ptr_eq` detects that nothing changed and the daemon exits rather than looping.
