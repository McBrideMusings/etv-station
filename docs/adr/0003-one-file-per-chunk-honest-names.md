# A playout file is one chunk, and its name must bracket its items

Each playout JSON file covers exactly one `chunk_hours` chunk on the local-time grid and holds every item scheduled in that chunk. Its name is `{start}_{finish}`, where `finish` is the chunk boundary once the chunk is full, or the last item's finish while the chunk is still being filled — a file's name never claims more time than the items inside it cover. A generation's items are merged into the existing chunk file for the window they fall in rather than each generation writing its own file. A startup scan and a per-roll-tick check detect and heal any span whose actual item coverage falls short of what its name claims.
