# Copy for examples/plugins/bumpers/text_card.rhai, read through ctx.read.
#
#   == id         starts a card
#   a line        centred text; it appears 0.5s after the line above it
#   *a line*      the same line in italics
#   > a credit    a smaller line, right-aligned under the widest line
#   ~ 0.6         wait 0.6s before the next line appears
#   ---           ends a screen: cut to black, then the next screen starts
#   @optional     (first line of a screen) kept only when the gap has room for it
#   {slot}        next_title, prev_title or channel, filled from the schedule
#   {slot|text}   the same, with `text` printed when the schedule has no value
#
# A {slot} with no value and no `|text` makes the card ineligible for that gap,
# so a literal {slot} never airs.
